# Landing page — Dra. Catalina Reyes

Projeto estático (HTML + CSS + JavaScript), sem dependências e sem build.

## Como executar
- Abra `index.html` no navegador (as fontes Playfair Display e DM Sans vêm do Google Fonts, então é preciso internet), ou
- rode um servidor local: `python3 -m http.server 8000` e acesse http://localhost:8000

## Estrutura
- `index.html`: estrutura e conteúdo
- `css/styles.css`: design tokens, layout, responsividade e animações
- `js/main.js`: navbar, menu mobile, animações de rolagem (Intersection Observer)
- `assets/images/`: fotos recortadas das imagens enviadas
- `assets/favicon.svg`
